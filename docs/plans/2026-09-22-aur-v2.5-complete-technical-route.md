## 0. 最终目标

项目第一原则保持不变：

MRI → (A, U) → R

其中：

- A：识别解剖结构、空间支撑与物理位置；
- U：识别病灶类型、3D 空间位置与大小；
- R：判断每个病灶与解剖结构之间的关系。

第一篇论文只要求把 A / U / R 三层做清楚。U_Q、motion、scanner shift、reliability E、multi-organ foundation-model pretraining 均为后续扩展。

## 1. v2.5 相比 v2.4 的核心修订

1. Level R pilot 不再预设 300–400 lesion：先做约 100–150 lesion 的双阅片 pilot，用于估计设计参数，再锁最终样本量。
2. 富集抽样加入 population correction：near-boundary / conflict enrichment 若不是完整标注留出集，all-lesion 主结果必须分层标准化或逆概率加权。
3. R ontology 拆层：primary_host、topography、adjacency、ambiguity 分开；juxtacortical 不作为 anatomy host class。
4. 阅片一致率与 ambiguous handling 预注册：在模型结果解盲前冻结规则。
5. 旧研究计划章节降为历史：不再让 v2.1/v2.2 的 relation Transformer / E / 四阶段训练 / M2-M3 路线与 v2.5 并列生效。
6. 代码语义清理：IndependentCandidateHead 明确等于 B1；删除误导性的 HostCompetitionHead alias；真正 B3 另建 CandidateCompetitionHead。

## 2. 完整 Gate 系统

### Gate 0 — Data geometry correctness

必须先证明 annotation coordinate 与 image coordinate 一致。

目标：
- 修复 fastMRI+ vertical flip；
- 建立统一 voxel ↔ physical-mm 坐标转换；
- 冻结所有 box/mask orientation convention。

Gate 0 未通过：禁止训练新的 U / R 主实验。

### Gate A/U — 基础感知是否可用

分别回答 X → A 与 X → U 是否在 held-out patient 上可用。

A 必须输出：
- anatomy_id
- mask
- bbox
- centroid_mm
- presence
- anatomy_embedding

U 必须输出：
- lesion_type
- confidence
- bbox_3d
- optional_mask
- centroid_mm
- size_mm3
- lesion_embedding

如果 U 失败：R 机制实验只能先使用 reference lesions，不能声称 end-to-end A/U/R 已成立。

### Gate R0 — Independent relation truth 是否成立

先判断当前影像分辨率下，radiologists 是否能定义可靠的 lesion–anatomy relation。

需要：
- 两名独立 reader；
- 第三 reader / consensus adjudication；
- 明确 ambiguity；
- 预注册 agreement rule。

如果某类 lesion 的单一 primary_host 人间一致性不够：该 subgroup 不允许继续把 single-host classification 当 primary endpoint。

### Gate R1 — Learned R 是否 beyond geometry

只有 Gate R0 通过后比较：

B0 / Bprior / Bgeo+ / B1 / B2 / B3 / B4 / B5

核心问题：does B4 add information beyond Bgeo+ and B2?

### Gate Robustness — A/U error 是否放大为 R error

只有 R1 证明 relation 有独立价值后，再研究 clean 与 degraded 下的 ΔA、ΔU、ΔR。

### Gate E — selective reliability

只有 Gate R1 = GO 且 robustness 中存在 residual relation failure，才训练 E = P(R correct | evidence)。

## 3. R ontology：不要把解剖结构、拓扑位置和不确定性混在一个 softmax

对 lesion U_j，定义：

R_j = { primary_host, topography, adjacency, ambiguity }

### primary_host

真正的 anatomy entity，例如：
- white matter
- cortex
- thalamus
- basal ganglia
- ventricle
- brainstem
- cerebellum

### topography

病灶空间类别，例如：
- periventricular
- juxtacortical
- cortical
- deep_white_matter
- infratentorial

### adjacency

例如：
- adjacent_to_cortex
- adjacent_to_ventricle
- crosses_boundary

### ambiguity

例如：
- certain
- two-host ambiguous
- multi-structure
- insufficient-resolution

推荐：
primary_host = white matter
topography = juxtacortical
adjacent_to = cortex

而不是把 juxtacortical 当成 primary_host。

对于 5 mm FLAIR 无法可靠区分的病例：
host_set = {white matter, cortex}
ambiguous = true

不强制产生单一错误 truth。

## 7. Level R annotation protocol

### 7.1 Annotation sample frame

目标 population：
all eligible held-out focal brain lesions

而不是只抽 conflict lesions。

### 7.2 Pilot size

第一轮 pilot 目标约 100–150 lesions。

用途：
- reader agreement
- ambiguous rate
- host prevalence
- method-discordance rate
- per-patient lesion clustering

这不是最终 efficacy cohort。

pilot 应覆盖至少几十名独立 patients，并避免单个高病灶负担 patient 主导样本。

pilot 只估设计参数，不做判定：§7.7 的一致率门槛与子组降级在最终队列上判，不在 pilot 判。精度参考：n=100/150 时 raw 一致率（p≈0.8）的 95% CI 半宽约 0.078/0.064，p_disc=0.10 的半宽约 0.059/0.048，相对误差约五成并直接传到 final N（n ∝ p_disc/d²）；H1 子组 40–60 例的半宽 0.10–0.12，判不了 80% 线。若要在 pilot 阶段就对 H1 单独下结论，H1 至少约 150 例。

### 7.3 Stratified pilot sampling

至少分：
H1: near-boundary / geometry-conflict
H2: stable white-matter / easy geometry

可进一步按 lesion size、lesion type、hemisphere、periventricular vs non-periventricular 分层。

为了估计困难病例，pilot 可以 oversample H1。

### 7.4 Reader design

每个 pilot lesion：
Reader A → independent label
Reader B → independent label

readers blinded to：
- model prediction
- Bgeo+ prediction
- clean pseudo host
- q1/q2/q3 host changes

若 A != B：
进入第三 reader 或 predefined consensus adjudication。

### 7.5 Annotation fields

每个 lesion：
- lesion_id
- primary_host
- acceptable_host_set
- topography
- adjacent_structures
- confidence_ordinal
- ambiguous_flag
- ambiguity_reason
- reader_id
- adjudicated_label

### 7.6 Agreement metrics

至少同时报告：
- raw agreement
- Cohen/Fleiss kappa
- Gwet AC1/AC2

避免只依赖 prevalence-sensitive kappa。

### 7.7 Agreement operational rule

在模型结果解盲前冻结。

建议预注册：
- 若某 subgroup 的 raw agreement < 80%，或 agreement statistic 的 95% CI 显示一致性不足；
- 则该 subgroup 不再使用“唯一 primary host”作为 primary endpoint；
- 转入 acceptable_host_set / ambiguity-aware secondary endpoint。

最终阈值必须在正式 annotation protocol 中由临床团队签字确认。该规则只在最终队列上执行（见 §7.2）；阈值的量纲（raw / κ / Gwet AC1）待拍板，见 §25 第 1 项。

### 7.8 Ambiguous endpoint

Primary endpoint：仅在 adjudication 后仍有唯一 host 的 certain lesions 中计算 accuracy、macro-F1、net rescue。

同时报告：
coverage = N_certain / N_all

Secondary endpoint：对 ambiguous lesion，定义 Y_j = {acceptable hosts}，prediction correct iff predicted_host ∈ Y_j。

## 8. 富集抽样与 population inference

### 8.1 原则

如果最终 Level R 不是完整标注整个 held-out lesion population，而是 oversample hard cases，则不能直接把 annotation cohort 的 net rescue 当总体结果。

### 8.2 首选：stratified standardization

设 strata h，例如 near-boundary / stable。

总体效应：
theta_population = Σ_h P_population(h) × theta_h

P_population(h) 必须来自原始 held-out population。

### 8.3 备选：inverse probability weighting

若 lesion i 被抽中的概率为 pi_i：
w_i = 1 / pi_i

用 weighted estimator 计算 accuracy、rescue、harm、net rescue。

patient bootstrap 时按 patient resample，并保留 lesion sampling weights。

### 8.4 最佳方案

如果资源允许，最终 held-out test set 全部进行 Level R 标注。此时无需 sampling correction；pilot enrichment 仅用于估设计参数。

## 9. Final N：pilot 后再算

不提前写死 300、400、470 或 700。

pilot 后估：
- p_disc
- reader ambiguity
- host prevalence
- patient ICC / clustering
- expected d = Acc(B4) - Acc(Bgeo+)

然后冻结：
- final N
- primary population
- sampling design
- analysis plan

再开始正式模型比较。

## 10. Baseline matrix

所有方法共享：
- same lesion instances
- same anatomy predictions
- same candidate ontology
- same patient split
- same geometry features
- same Level R truth

### B0 — deterministic lookup

class-aware overlap → zero-overlap nearest candidate

### Bprior — anatomy prior

P(host | lesion type, side, coarse location)

必须包含：
- majority
- type only
- type + side
- type + side + coarse location

### Bgeo+ — strong geometry

至少：
1. logistic regression
2. sklearn.ensemble.HistGradientBoostingClassifier
3. 2-layer MLP

默认不新增 XGBoost 依赖。

### B1 — IndependentCandidateHead

score_ij = MLP(a_i, u_j, g_ij)
host_j = softmax_i(score_ij)

candidate 在 softmax 前彼此不交互，因此 B1 不等于 relational candidate competition。

### B2 — local ROI classifier

输入 lesion-centred local MRI context，直接预测 host。

意义：排除真正需要 pair reasoning 之前，local appearance 自己是否已经足够。

### B3 — CandidateCompetitionHead

固定 lesion j：
z_ij = Fuse(a_i, u_j, g_ij)
Z_j = [z_1j ... z_Kj]
Z'_j = CandidateInteraction(Z_j)
host = softmax_i h(Z'_ij)

interaction 只发生在同一 lesion 的 K 个 candidate anatomy 间。

默认 no cross-lesion attention。

### B4 — B3 + local boundary evidence

加入 pair-specific local image/boundary evidence l_ij：

z_ij = Fuse(a_i, u_j, g_ij, l_ij)

B4 是第一篇 relation 主模型候选。

### B5 — oracle ceiling

GT/reference lesion + best available anatomy geometry。

只用于估计 ceiling，不参与 superiority claim。

## 12. Gate R1 主统计

### 12.1 Population

primary：all eligible lesions

near-boundary / conflict：pre-specified subgroup

不能只在 conflict subset 宣称优势。

### 12.2 Metrics

- host accuracy
- macro-F1
- balanced accuracy
- top-k host accuracy
- coverage
- rescue
- harm
- net rescue

rescue = comparator wrong, model correct  
harm = comparator correct, model wrong  
net rescue = rescue - harm

最重要 comparator = Bgeo+。

### 12.3 Inference

主方法：patient-level cluster bootstrap。

辅助：paired McNemar。

若采用 enrichment sampling，stratified standardization / IPW 必须进入 bootstrap estimator。

### 12.4 Gate R1 GO

建议预注册：
- 95% CI(net rescue B4 - Bgeo+) > 0
- B4 > Bprior
- B4 > Bgeo+
- B4 > B2

并且：
- all-lesion population 成立；
- 改善不是只来自 lesion-type prior；
- ambiguity / coverage 被完整报告。

### 12.5 Gate R1 NO-GO

若 B4 ≈ Bgeo+ 或 B4 ≈ B2，则停止把 learned relation 作为 primary method contribution。

保留 X → A、X → U 与 geometry/topography localization 作为 structured perception 工作。

## 13. Robustness：第二阶段而不是项目定义

只有 R1 GO 后才做。

### 13.1 robust perception control

先训练 corruption/noise-aware anatomy model，再测 q1/q2/q3。

如果 robust A 让 host failures 压回 reference-instability floor，则停止 claim “relation model is required for degradation rescue”。

### 13.2 Error propagation

对同一 lesion 测：
- ΔA = anatomy error change
- ΔU = lesion perception error change
- ΔR = relation error change

重点分析 small ΔA / ΔU 是否导致 large ΔR，但不把 ratio 类指标作为唯一主结论。

## 14. Reliability E

仅当 R1 GO 且 residual R failures remain 才引入。

比较：
- maximum softmax
- entropy
- anatomy uncertainty
- lesion uncertainty
- local NRMSE
- learned failure prediction

必须在 within-severity strata 中评估，防止 E 只学习 q-level。

## 22. 第一篇论文最稳叙事

核心：

## 25. 未决事项（PR #6 评审，待拍板）

以下 5 项在 PR #6 评审（pullrequestreview-5274706631）中提出，涉及研究设计，须用户与临床团队拍板后再改正文。改前正文以现状为准，但不得据此开始正式标注或模型比较。

1. **一致率门槛的量纲（§7.7）。** 现写 raw agreement 80%。宿主分布约 79% 白质 / 19% 皮层时，两读者机会一致率 p_e ≈ 0.66，raw 0.80 对应 κ ≈ 0.41，raw 0.90 对应 κ ≈ 0.71。建议：Gwet AC1 的 95% CI 下限 ≥ 0.6，或 raw ≥ 0.90；只在最终队列上判。
2. **关系模型评估用患者级五折 CV 还是单一留出（§9）。** 按 n = 7.84·p_disc/d² 再乘 1.3–1.5 设计效应：p_disc 0.10、d 0.04 需 640–735 个病灶；d 0.03 需 1130–1310；p_disc 0.06、d 0.05 需 245–280。按患者划 20% 留出只有约 50 名患者、约 260 个小病灶，全标也只能检出 6–8 个点；要检 3–4 个点须让全部 1297 个小病灶在各自折里当测试，两名读者各读约 2600 例（每例 1.5 分钟约 32 小时）。这一条决定 Level R 的工作量。
3. **主终点人群（§7.8 与 §12.1 矛盾）。** §7.8 只算裁定后“确定”的病灶，§12.1 说主人群是全部病灶。剔除模糊病灶等于剔除困难病例，B4 可能有余量的地方正好被抹掉。建议：主终点 = 全部病灶，用集合值正确性（predicted_host ∈ acceptable_host_set，确定病灶的集合只有一个元素）；确定病灶子集单列报告，并报告 coverage。
4. **ventricle 是否作为 primary_host（§3）。** V7 §5 与 v2.4 定的是脑室与 CSF 只作地标，不作宿主（探针里干净图就有 19 个病灶被查表判给 CSF）。若保留，限定为脑室内病灶（罕见）；室周 WMH 的宿主是白质、topography 是 periventricular。
5. **H1 分层的定义（§7.3）。** 若“geometry-conflict”指方法不一致，只能用不含 B4 的方法（如 B0 vs Bgeo+）且在 B4 存在前冻结，否则抽样与结局相关。更稳妥的是纯几何准则：病灶中心到最近候选结构边界的距离小于 t mm（SynthSeg 距离变换可算），对全部病灶都可计算，抽样概率 π_i 随之明确。
