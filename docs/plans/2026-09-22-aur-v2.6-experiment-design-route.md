## 0. 最终目标

项目第一原则保持不变：

MRI → (A, U) → R

其中：

- A：识别解剖结构、空间支撑与物理位置；
- U：识别病灶类型、3D 空间位置与大小；
- R：判断每个病灶与解剖结构之间的关系。

第一篇论文只要求把 A / U / R 三层做清楚。U_Q、motion、scanner shift、reliability E、multi-organ foundation-model pretraining 均为后续扩展。

## 1. 版本修订记录

### v2.6 相比 v2.5（2026-09-22 晚）

1. 新增 Gate 0.5：在任何医生读片前，对全部 1297 个小病灶算干净 SynthSeg 下的宿主分布、交界面距离、几何余量与困难组占比（§4.5）。

3. 排除单一 20% 留出；"全标 1297"与"困难组全标 + 简单组概率抽样"两个设计在 pilot 后用患者聚簇模拟功效择一，成本按分层实测读片时间算（§8.4、§9）。

5. 主终点 = 全部病灶、集合值正确性；单一宿主真值占比（singleton rate，即原 coverage）单独报告（§7.8、§12.1）。
6. 脑室与 CSF 只作地标，不作 primary_host；脑室内病灶记 other（§3）。
7. 评估协议：外层五折患者级 CV 只用一次，模型选择在内层；折按 h5 的 patient_id 划分并断言不重叠；外层测试折标签封存；700 例非约束性无效性中期分析前冻结模型（§12.6–§12.9）。
8. 读者字段新增 not_a_lesion、A_local_quality、每例用时；可接受集合最多两个元素（§7.5）。
9. 脑侧 U 降为次要系统实验：第一篇主实验是"给定病灶实例 + 预测解剖 → R"（§6.3、§20）。
10. B4 / B2 / Bgeo+ 的初始配置与训练标签规则写死（§10.1）：B4 同时用图像小块与距离图；训练先用伪标签，医生标签微调为预注册的升级路径；B2 的小块与 B4 绑定。
11. 200/201 与低分辨率系列分层；pilot 两层都要覆盖（§7.3、§15）。
12. §25 由"未决事项"改为"决定记录"。

### v2.5 相比 v2.4

1. Level R pilot 不再预设 300–400 lesion：先做约 100–150 lesion 的双阅片 pilot，用于估计设计参数，再锁最终样本量。
2. 富集抽样加入 population correction：near-boundary / conflict enrichment 若不是完整标注留出集，all-lesion 主结果必须分层标准化或逆概率加权。
3. R ontology 拆层：primary_host、topography、adjacency、ambiguity 分开；juxtacortical 不作为 anatomy host class。
4. 阅片一致率与 ambiguous handling 预注册：在模型结果解盲前冻结规则。
5. 旧研究计划章节降为历史：不再让 v2.1/v2.2 的 relation Transformer / E / 四阶段训练 / M2-M3 路线与 v2.5 并列生效。
6. 代码语义清理：IndependentCandidateHead 明确等于 B1；删除误导性的 HostCompetitionHead alias；真正 B3 另建 CandidateCompetitionHead。

## 2. 完整 Gate 系统

### Gate 0 — Data geometry correctness

必须先证明 annotation coordinate 与 image coordinate 一致。

目标：
- 修复 fastMRI+ vertical flip；
- 建立统一 voxel ↔ physical-mm 坐标转换；
- 冻结所有 box/mask orientation convention。

Gate 0 未通过：禁止训练新的 U / R 主实验。

### Gate 0.5 — 全集几何盘点（读片前）

在任何医生读片之前，对全部 1297 个小病灶（165 名患者）在干净 SynthSeg 分区上算：查表宿主分布、病灶表面到最近交界面的距离 d_interface、几何余量 Δd、t = 2/3/4/5 mm 下的困难组占比、每患者病灶数、200/201 与低分辨率系列分开（§4.5）。

GO：在冻结的 t 下困难组占比 ≥ 15%。否则关系主线降级为 §8 退路（几何绑定的失败模式与人标发布），不再投入读片。

### Gate A/U — 基础感知是否可用

分别回答 X → A 与 X → U 是否在 held-out patient 上可用。

A 必须输出：
- anatomy_id
- mask
- bbox
- centroid_mm
- presence
- anatomy_embedding

U 必须输出：
- lesion_type
- confidence
- bbox_3d
- optional_mask
- centroid_mm
- size_mm3
- lesion_embedding

如果 U 失败：R 机制实验只能先使用 reference lesions，不能声称 end-to-end A/U/R 已成立。

v2.6：脑侧 U 不是关系论文的前置门。第一篇主实验固定为 reference lesion instances + predicted anatomy → R（§6.3）；X → U → R 只作次要系统实验。膝侧 H1 重跑照做。

### Gate R0 — Independent relation truth 是否成立

先判断当前影像分辨率下，radiologists 是否能定义可靠的 lesion–anatomy relation。

需要：
- 两名独立 reader；
- 第三 reader / consensus adjudication；
- 明确 ambiguity；
- 预注册的两层一致率规则（§7.7）：全体 raw 一致率 95% CI 下限 ≥ 0.80；困难组 H1 raw 点估计 ≥ 0.70；皮层等少数类的 positive agreement 与混淆矩阵必须报告；κ 与 Gwet AC1 报告但不作门。

只看全体 raw 有漏洞：两读者对白质全一致、对皮层只一半一致时，全体 raw 0.893、κ 0.62、AC1 0.88 全部过线，而皮层 positive agreement 只有 0.67、困难组内 raw 只有 0.52（`docs/verification/2026-09-22-external-review-check/power_sim_output.txt` 第 [2] 段）。

如果某分层的单一 primary_host 人间一致性不够：该分层不允许继续把 single-host classification 当 primary endpoint，转集合值终点。

### Gate R1 — Learned R 是否 beyond geometry

只有 Gate R0 通过后比较：

B0 / Bprior / Bgeo+ / B1 / B2 / B3 / B4 / B5

核心问题：does B4 add information beyond Bgeo+ and B2?

### Gate Robustness — A/U error 是否放大为 R error

只有 R1 证明 relation 有独立价值后，再研究 clean 与 degraded 下的 ΔA、ΔU、ΔR。

### Gate E — selective reliability

只有 Gate R1 = GO 且 robustness 中存在 residual relation failure，才训练 E = P(R correct | evidence)。

## 3. R ontology：不要把解剖结构、拓扑位置和不确定性混在一个 softmax

对 lesion U_j，定义：

R_j = { primary_host, topography, adjacency, ambiguity }

### primary_host

真正的 anatomy entity，例如：
- white matter
- cortex
- thalamus
- basal ganglia
- brainstem
- cerebellum
- other（含罕见的脑室内病灶）

脑室与 CSF 不是 primary_host，只作地标（topography = periventricular、adjacency = adjacent_to_ventricle）。真正的脑室内病灶记 primary_host = other，计入 singleton rate 报告，不进宿主准确率。理由：探针干净图上就有 19/780 病灶被查表判给 CSF，那是 5 mm 层上的部分容积伪标签错误；若脑室算宿主，任何学过"CSF 附近其实是白质"的模型都能在这 2.4% 上白得分数（2026-09-22 决定，§25 第 4 项）。

### topography

病灶空间类别，例如：
- periventricular
- juxtacortical
- cortical
- deep_white_matter
- infratentorial

### adjacency

例如：
- adjacent_to_cortex
- adjacent_to_ventricle
- crosses_boundary

### ambiguity

例如：
- certain
- two-host ambiguous
- multi-structure
- insufficient-resolution

推荐：
primary_host = white matter
topography = juxtacortical
adjacent_to = cortex

而不是把 juxtacortical 当成 primary_host。

对于 5 mm FLAIR 无法可靠区分的病例：
host_set = {white matter, cortex}
ambiguous = true

不强制产生单一错误 truth。

## 4. Gate 0 与 Gate 0.5：坐标、数据引擎与全集几何盘点

### 4.1 正式修复

将 fastMRI+ CSV box 映射统一实现于 data engine。

已验证的 vertical mapping：
y_raw_start = nr - y_csv - h
y_raw_end = nr - y_csv

禁止 probe helper 和 training loader 各自维护不同转换。

### 4.2 必需测试

1. synthetic known-box test：构造已知像素目标，确认 CSV-space → RSS-space 后 box 精确覆盖目标。
2. round-trip test：CSV → RSS → CSV 坐标误差为 0。
3. physical-coordinate test：voxel coordinate × spacing 得到一致 mm 坐标。
4. overlay smoke test：brain / knee 各抽样多卷生成 raw image + transformed boxes。
5. manifest：记录 box_coordinate_convention、image_orientation、spacing、transform_version。

### 4.3 旧导出处理

`/data2/congcong/data/FM_data/derived/fastmri_knee/leg2`（约 56 GB）是按原样框生成的，修复后整批作废：manifest 的 `transform_version` 标为旧版本，加载器遇到旧版本必须拒绝，不得静默沿用；旧导出不删除。图像数组与框约定无关，修复不必重导 56 GB：新建导出根，各卷目录用链接指向旧根，只换坐标文件与 manifest。

### 4.4 折按患者划分与 CI

fastMRI 的 h5 文件自带 `patient_id` 属性。实测 252 卷有框 FLAIR 对应 252 个不同 patient_id，165 卷小病灶卷对应 165 名患者，训练集与验证集之间无重叠患者（`docs/verification/2026-09-22-external-review-check/patient_id_check_output.txt`）。生成折清单时必须显式建 file → patient_id 映射，并断言任意两折的患者集合不相交；该断言现在会自然通过，加入 T1 / T1POST 卷后未必。同一 PR 加 GitHub Actions 跑 CPU 测试（约 35 秒）。

### 4.5 Gate 0.5：全集几何盘点

在读片前对全部 1297 个小病灶在干净 SynthSeg 分区上计算，落盘 `docs/verification/<日期>/brain_frame.md`：

- 查表宿主分布（33 类无类别限定，与探针同规则）；
- d_interface：病灶表面（框内体素）到最近"任意两块候选脑区交界面"的距离，在带物理间距的 EDT 上算。它与"到最近其他候选结构的距离"是同一个量，差别在一个体素对角线之内（一卷实测：median 1.4 mm，100% ≤ 5.09 mm，`interface_check_output.txt`）。层厚 5 mm 意味着相邻层的结构中心至少 5 mm 远，t 取 2–4 mm 时这是一个面内准则，跨层邻接进不来；
- 几何余量 Δd = 第二近候选距离 − 最近候选距离（连续量，供 §12.9 的曲线）；
- t = 2 / 3 / 4 / 5 mm 下的困难组占比；
- 每患者小病灶数、单层比例；
- 200/201 系列与低分辨率系列分开报告。

t 的冻结规则（预注册，模型存在前执行）：初值 3 mm；在 {2, 3, 4, 5} 中取使困难组占比 ≥ 15% 的最小值；5 mm 仍不足 15% 则 Gate 0.5 不过。警示：那一卷里 89% 的白质体素离某个交界面不到 3 mm；若病灶按白质体素分布，困难组会是大半而不是两成，"困难组"就失去分层意义，这正是 t 必须看全集分布后再定的原因。探针的 78.7% 白质宿主来自按病灶数挑出的 24 卷，不是总体估计。

计算量：单卷约 3.6 s，252 卷约 15 CPU 分钟（单线程）。

2026-09-24 实测（`scripts/brain_frame.py`，`docs/verification/2026-09-24/gate05/brain_frame.md`）：1297 个小病灶里 d_interface ≤ 2 mm 的占 58.2%（≤ 0 mm 42.0%、≤ 5 mm 88.7%），按上面的规则 t = 2 mm 但困难组过半，正是上一段警示的情形；t 未冻结，分层方式待用户定（三个选项见 `STATUS.md` §2）。宿主类合并左右、脑室/CSF 只作地标，d_interface 用"到第二近宿主类的距离"（计划 D8/D9）。

## 5. Stage A：Anatomy parsing

第一篇只冻结对 R 有用的候选 anatomy ontology，不追求万能 anatomy model。

brain 主战场优先结构：
- white matter
- cortex
- lateral ventricles
- deep gray nuclei
- brainstem
- cerebellum
- CSF / background as needed

A 指标：
- Dice
- HD95
- presence accuracy
- centroid error (mm)
- lesion-neighbourhood boundary distance
- local surface displacement
- candidate-presence recall

允许多层来源：
A_GT / A_pred / A_pseudo

最终 R superiority 中，baseline 与 learned R 必须使用同层级 anatomy input，不能一边 GT、一边 predicted。

## 6. Stage U：Lesion parsing

### 6.1 默认 detector

当前默认使用 dense centre-heatmap，而不是旧 DETR/Hungarian。

输出：
- heatmap
- offset
- size
- lesion type
- lesion embedding

### 6.2 修复 box flip 后必须重跑 H1

旧 H1 detector failure 不能继续作为 detector architecture 的最终证据。

修复后报告：
- lesion recall
- FROC
- classification
- center error in mm
- box IoU
- small-lesion subgroup
- per-patient detection coverage

### 6.3 两级 relation 实验（v2.6：主次固定）

Primary scientific experiment（第一篇主实验）：
reference lesion instances（数据集自带框，Gate 0 转换后）+ predicted anatomy（SynthSeg）→ R

Secondary system experiment：
predicted lesion + predicted anatomy → R

这样分解 U failure 与 R failure。脑侧检测器不是关系论文的前置门：1297 个小病灶里 1240 个是同一标签"非特异白质病灶"，79.3% 单层、42% 面内不超过 6 mm，样本比膝少四倍；把 X → U 做成完整检测器与 R 的核心科学问题关系很弱。膝侧 H1 修复后重跑照做，用于了结被翻转框污染的裁决。

## 7. Level R annotation protocol

### 7.1 Annotation sample frame

目标 population：
all eligible held-out focal brain lesions

而不是只抽 conflict lesions。

### 7.2 Pilot size

第一轮 pilot 目标约 100–150 lesions。

用途：
- reader agreement
- ambiguous rate
- host prevalence
- method-discordance rate
- per-patient lesion clustering

这不是最终 efficacy cohort。

pilot 应覆盖至少几十名独立 patients，并避免单个高病灶负担 patient 主导样本。

pilot 只估设计参数，不做判定：§7.7 的一致率门槛与子组降级在最终队列上判，不在 pilot 判。精度参考：n=100/150 时 raw 一致率（p≈0.8）的 95% CI 半宽约 0.078/0.064，p_disc=0.10 的半宽约 0.059/0.048，相对误差约五成并直接传到 final N（n ∝ p_disc/d²）；H1 子组 40–60 例的半宽 0.10–0.12，判不了 80% 线。若要在 pilot 阶段就对 H1 单独下结论，H1 至少约 150 例。

### 7.3 Stratified sampling（分层定义与模型无关）

H1（困难组）：d_interface ≤ t，定义见 §4.5。H2：其余。定义只依赖干净 SynthSeg 分区，不依赖任何宿主答案、B0、Bgeo+ 或 B4，因此抽样概率 π_i 对全部病灶都可算，也不会与结局相关。

连续量 Δd（几何余量）同时记录；论文报告 net rescue 随 Δd 的曲线（§12.9），不只报二元 H1/H2。

第二个必分的层：采集系列（200/201 全分辨率 1077 个小病灶 vs 低分辨率系列 220 个）。pilot 两层都要有（低分辨率 ≥ 30 例）；若低分辨率层的 raw 一致率明显更低（< 0.70），第一篇主人群定为 200/201，低分辨率作次要稳健性队列。

2026-09-24 实测修正：系列号不等于分辨率——205/209/210 与 200 同为 320×320 @ 0.6875 mm，真正 0.86 mm 面内的是 202（部分）/203/206 共 90 个小病灶，另有 43 个在 3 mm 层厚的卷上。分层改按实测间距（`inplane_0.69_slice_5` 1175 / `inplane_0.86_slice_5` 79 / `inplane_0.62_slice_3` 32 / `inplane_0.86_slice_3` 11），系列号分层只作对照（`docs/verification/2026-09-24/gate05/brain_frame.md`）。

可进一步按 lesion size、hemisphere、periventricular vs non-periventricular 分层。为了估计困难病例，pilot 可以 oversample H1。

### 7.4 Reader design

每个 pilot lesion：
Reader A → independent label
Reader B → independent label

readers blinded to：
- model prediction
- Bgeo+ prediction
- clean pseudo host
- q1/q2/q3 host changes

若 A != B：
进入第三 reader 或 predefined consensus adjudication。

### 7.5 Annotation fields

每个 lesion：
- lesion_id
- primary_host
- acceptable_host_set
- topography
- adjacent_structures
- confidence_ordinal
- ambiguous_flag
- ambiguity_reason
- reader_id
- adjudicated_label
- not_a_lesion（读者不认可该框时的出口；预注册处理：不进主终点，单独报告数量）
- A_local_quality ∈ {acceptable, suspicious}（"病灶附近的分区边界看起来可靠吗"；不要求改画分区）
- time_seconds（每例用时，替换 1.5 分钟的假设）

acceptable_host_set 最多两个元素。不设"无法判断"的逃生口：模糊病灶必须给出集合。

至少同时报告：
- raw agreement
- Cohen/Fleiss kappa
- Gwet AC1/AC2

避免只依赖 prevalence-sensitive kappa。

### 7.7 Agreement operational rule（两层，v2.6 定稿）

在模型结果解盲前冻结，只在最终队列上判（pilot 只估参数，见 §7.2）。

1. 全体：raw 一致率的 95% CI 下限 ≥ 0.80，否则 Gate R0 不过。
2. 困难组 H1：raw 点估计 ≥ 0.70 才允许 H1 使用单一宿主终点；否则 H1 只用集合值终点。
3. 必须报告：皮层等少数类的 positive agreement、混淆矩阵、低分辨率层单独的 raw。
4. κ 与 Gwet AC1/AC2 报告，不作门。按探针宿主分布，AC1 0.6 只相当于 raw 约 0.65，比 0.80 还松；κ 被 0.655 的机会一致率拖低。两者都不适合单独当门（κ 悖论与 AC1 的讨论见 JTO Clin Res Rep 2023，PMC10820331）。

最终阈值由临床团队在正式 annotation protocol 中签字确认。

### 7.8 Endpoint 定义（v2.6 定稿）

Primary endpoint：全部病灶，集合值正确性。Y_j = acceptable_host_set（裁定后），prediction correct iff predicted_host ∈ Y_j；确定病灶的 Y_j 只有一个元素。

同时报告：
singleton rate = N(|Y_j| = 1) / N_all（即 v2.5 的 coverage，统一用本名）

确定病灶子集（|Y_j| = 1）的 accuracy、macro-F1、net rescue 单列报告。

模糊病灶的集合若是 {white matter, cortex}，Bgeo+ 与 B4 都"答对"，对 net rescue 贡献为零；集合值评分对 B4 是保守的。

## 8. 富集抽样与 population inference

### 8.1 原则

如果最终 Level R 不是完整标注整个 held-out lesion population，而是 oversample hard cases，则不能直接把 annotation cohort 的 net rescue 当总体结果。

### 8.2 首选：stratified standardization

设 strata h，例如 near-boundary / stable。

总体效应：
theta_population = Σ_h P_population(h) × theta_h

P_population(h) 必须来自原始 held-out population。

### 8.3 备选：inverse probability weighting

若 lesion i 被抽中的概率为 pi_i：
w_i = 1 / pi_i

用 weighted estimator 计算 accuracy、rescue、harm、net rescue。

patient bootstrap 时按 patient resample，并保留 lesion sampling weights。

### 8.4 两个候选设计（pilot 后择一）

方案 A：最终 held-out 病灶全部标注（约 1297），无需 sampling correction。

方案 B：困难组 H1 全标 + 简单组 H2 概率抽样（记录 π_i），用 §8.2 标准化或 §8.3 IPW 校正（聚簇数据下两阶段设计的推断见 Rivera-Rodriguez，Stat Med 2019，PMID 31359448）。

预期要写实。主终点是全部病灶的 net rescue，H2 占约八成权重，它的均值再"容易"也得估准。解析计算（无聚簇）：H1 全标 + H2 抽 300 的标准误是全标的 1.38 倍，抽 600 是 1.12 倍；Neyman 最优分配应把约六成名额给 H2，与"简单组少标"相反。模拟（`docs/verification/2026-09-22-external-review-check/power_sim_output.txt` 第 [3] 段，ICC 约 0.02）：80% 功效对应的最小可检 d，全标约 0.03，H1 全标 + H2 600 约 0.035，H1 全标 + H2 300 约 0.04，随机 700 约 0.045。每小时读片买到的信息量四种设计相近；简单病灶恰是标得最快、最少需要裁定的，砍掉它们省下的时间最少。

因此 pilot 后的模拟必须按分层实测读片时间算工时，选"功效 ≥ 80% 且工时最低"的设计；不预设方案 B 能省几十小时。真正能省工时的只有把主终点改成 H1 子组，但这与 §12.1 矛盾，不采用。

## 9. Final N：pilot 后用患者聚簇模拟定

不提前写死 300、400、470、700 或 1297。设计效应公式 DE = 1 + (m_eff − 1)·ICC（脑侧实测 m_eff = 29.45，ICC 0.05 时 2.42）只作警报，不作最终样本量计算器。

pilot 后实测：
- p_disc（分 H1 / H2）与 q（分歧中 B4 答对的比例）
- reader ambiguity、singleton rate
- host prevalence
- patient ICC 与每患者病灶数分布（用真实分布，不用均值）
- 每例读片时间（分层）

然后对方案 A / B 各做蒙特卡洛：逐病灶 Z_j ∈ {+1（B4 对、Bgeo+ 错）, −1（反之）, 0}，按患者重采样得 net rescue 的 CI，功效 = P(CI 下限 > 0)。模板脚本 `docs/verification/2026-09-22-external-review-check/power_sim.py`（其中的患者异质性模型是假设，pilot 后换成实测）。

然后冻结：
- final N
- primary population（全部 FLAIR 还是只用 200/201）
- sampling design
- analysis plan
- 训练标签阶段（§10.1 的升级规则）

再开始正式模型比较。

## 10. Baseline matrix

所有方法共享：
- same lesion instances
- same anatomy predictions
- same candidate ontology
- same patient split
- same geometry features
- same Level R truth

### B0 — deterministic lookup

class-aware overlap → zero-overlap nearest candidate

### Bprior — anatomy prior

P(host | lesion type, side, coarse location)

必须包含：
- majority
- type only
- type + side
- type + side + coarse location

### Bgeo+ — strong geometry

至少：
1. logistic regression
2. sklearn.ensemble.HistGradientBoostingClassifier
3. 2-layer MLP

默认不新增 XGBoost 依赖。

### B1 — IndependentCandidateHead

score_ij = MLP(a_i, u_j, g_ij)
host_j = softmax_i(score_ij)

candidate 在 softmax 前彼此不交互，因此 B1 不等于 relational candidate competition。

### B2 — local ROI classifier

输入 lesion-centred local MRI context，直接预测 host；不看解剖分区，不算几何。

意义：排除真正需要 pair reasoning 之前，local appearance 自己是否已经足够。

公平约束（v2.6）：B2 的图像小块与 B4 的病灶编码器输入完全一致（同尺寸、同层数、同通道），网络就是 B4 的病灶编码器加一个线性头（§10.1）。小块太小 B2 看不到旁边的皮层，B4 白捡便宜；太大 B2 就变成全脑模型。

### B3 — CandidateCompetitionHead

固定 lesion j：
z_ij = Fuse(a_i, u_j, g_ij)
Z_j = [z_1j ... z_Kj]
Z'_j = CandidateInteraction(Z_j)
host = softmax_i h(Z'_ij)

interaction 只发生在同一 lesion 的 K 个 candidate anatomy 间。

默认 no cross-lesion attention。

### B4 — B3 + local boundary evidence

加入 pair-specific local image/boundary evidence l_ij：

z_ij = Fuse(a_i, u_j, g_ij, l_ij)

l_ij 同时使用图像小块与候选距离图（2026-09-22 拍板）。B4 是第一篇 relation 主模型，初始配置见 §10.1。

### B5 — oracle ceiling

GT/reference lesion + best available anatomy geometry。

只用于估计 ceiling，不参与 superiority claim。

### 10.1 初始配置与训练标签（2026-09-22 拍板；细节在内层按预注册范围选，见 §12.6）

候选集：病灶表面 15 mm 内出现的宿主类别（white matter、cortex、thalamus、basal ganglia、brainstem、cerebellum、other），K ≤ 7，另加 none。左右半球并入 side 特征，不作为独立候选。

共享病灶编码器 E_u（B2 与 B1–B4 共用）：
- 输入：以病灶为中心的小块，面内 24 mm × 24 mm（重采样到 0.75 mm，32 × 32 px），3 层（病灶层 ± 1）；通道 = 逐卷 z-score 的 FLAIR、病灶框掩膜
- 结构：4 个卷积块（32-64-64-128）+ 全局池化 → 128 维

解剖 token a_i：宿主类别嵌入（32 维）⊕ 共享几何 g_ij（§11）→ MLP → 64 维。第一篇脑侧不训练解剖编码器。

逐对局部证据 l_ij：与 E_u 同一小块几何；通道 = FLAIR、病灶框掩膜、候选 i 的带符号距离图（mm，截断 ±10）、候选 i 的二值掩膜；3 个卷积块（16-32-32）→ 32 维。

融合与竞争：z_ij = MLP([a_i, u_j, g_ij, l_ij]) → 64 维（B3 去掉 l_ij）；1 层 Transformer encoder 在同一病灶的 ≤ 7 个候选间交互（d 64、4 头、FFN 128）；线性打分后对候选 + none 做 softmax。B1 = 无交互版本。

损失：交叉熵；标签为集合时用集合内概率之和的负对数。优化：AdamW，lr 1e-3，wd 1e-4，批 64 个病灶，40 个 epoch，按内层集合值准确率早停。增广：面内翻转、±10% 强度缩放；伪标签预训阶段可用噪声视图 q1/q2 作输入增广（标签仍是干净图查表）。

内层选择的预注册候选范围：小块边长 {16, 24, 32} mm；层数 {1, 3}；交互层数 {1, 2}；证据分支宽度 {16, 32}。从初始配置出发按单因素变化，总数 ≤ 12 个配置。范围一经预注册不再扩充。

训练标签（"先用软件算"）：
- 阶段 1（默认）：全部学习方法（Bgeo+、B1–B4）在伪标签 C1（干净图查表）上拟合；预训池 = 非测试患者的全部卷（含无小病灶标注的卷），由 §4.4 的患者断言保证不含测试患者。
- 升级路径（预注册，在最终队列解盲前决定）：若在 pilot 标签上，伪标签训练的 B4 在 H1 层的集合值准确率不超过同样伪标签拟合的 Bgeo+ 0.02 以上，则最终队列改为"伪标签预训 + 外层训练折医生标签微调"，Bgeo+ 同样在外层训练折医生标签上重新拟合。任一阶段内，所有学习方法必须使用同一标签来源。
- 风险写明：只用伪标签训练的 B4 学的是模仿 B0，在 B0 出错的困难病例上被教了错答案；这是 pilot 就要检查的事。

Bgeo+：logistic regression、HistGradientBoosting、2 层 MLP（64-64）；输入 = §11 的 16 维 + 脑侧附加 + d_interface + Δd；拟合标签与 B4 当前阶段相同。

## 12. Gate R1 主统计

### 12.1 Population

primary：all eligible lesions，集合值正确性（§7.8）

near-boundary / conflict（H1，§7.3）：pre-specified subgroup

不能只在 conflict subset 宣称优势。

### 12.2 Metrics

- host accuracy（集合值）
- macro-F1
- balanced accuracy
- top-k host accuracy
- singleton rate（原 coverage）
- rescue
- harm
- net rescue

rescue = comparator wrong, model correct  
harm = comparator correct, model wrong  
net rescue = rescue - harm

最重要 comparator = Bgeo+。

### 12.3 Inference

主方法：patient-level cluster bootstrap。

辅助：paired McNemar。

若采用 enrichment sampling，stratified standardization / IPW 必须进入 bootstrap estimator。

### 12.4 Gate R1 GO

建议预注册：
- 95% CI(net rescue B4 - Bgeo+) > 0
- B4 > Bprior
- B4 > Bgeo+
- B4 > B2

并且：
- all-lesion population 成立；
- 改善不是只来自 lesion-type prior；
- ambiguity / coverage 被完整报告。

### 12.5 Gate R1 NO-GO

若 B4 ≈ Bgeo+ 或 B4 ≈ B2，则停止把 learned relation 作为 primary method contribution。

保留 X → A、X → U 与 geometry/topography localization 作为 structured perception 工作。

### 12.6 评估协议：外层五折患者级 CV，模型选择在内层

- 折按 h5 `patient_id` 划分（§4.4），外层五折，每个外层测试折只用一次；所有外层测试折的 out-of-fold 预测汇总后算 net rescue 与患者 bootstrap CI。
- 按方法分级：B0、Bprior 无超参，只跑外层；Bgeo+ 在外层训练折内做内层五折选 HGB 深度/学习率、MLP 宽度、LR 的 C；B1–B4 在内层按 §10.1 的预注册范围选配置。归一化、特征缩放、阈值全部在外层训练折内完成。
- 依据：不能在测试折上调参、必须按患者划分（JMIR AI 2023 教程，PMC11041453；Radiology: AI 2023 指南，PMC10388213）。前者同时指出样本大、超参搜索小的场景嵌套 CV 收益只有 1–2 个点，所以对无超参的方法不强制嵌套。
- 算力：B1–B4 是小头，估计合计不超过一两个 GPU 天（NOT_EVIDENCE）。

### 12.7 标签封存

Level R 标注完成后按外层折封存：`data/level_r/outer_fold_k/train_labels.csv` 供开发；`test_labels.csv` 加 sha256 清单封存，只有 `anatobind/eval/level_r_stats.py` 在最终评估时读取。开发者在研究过程中不查看外层测试折的逐例对错。

### 12.8 中期无效性分析（非约束性）

按折顺序读片，累计 ≥ 700 个已标注病灶时做一次：若 net rescue（B4 − Bgeo+）的 95% CI 上限 < 0.02，停止 PR-D，第一篇改为退路版本。前提：B4 在中期分析前已按预注册冻结。只允许"停"，不允许"宣称成功"。若中期后仍想改模型，则中期队列退回开发集，最终评估需要新的独立队列。

### 12.9 机制分层报告

- net rescue 随几何余量 Δd 的曲线（分箱 + 患者 bootstrap 带）。
- 按读者字段 A_local_quality 分为 A-good / A-bad 两组分别报 net rescue：B4 只在 A-bad 上赢，机制解释是"局部图像证据纠正分区/几何错误"；在 A-good 上仍赢，才是 beyond-geometry 的证据。B4 能看原始图像而 Bgeo+ 不能，所以"A 的误差是共模"这句话不严格成立。
- 200/201 与低分辨率层分别报告。

## 13. Robustness：第二阶段而不是项目定义

只有 R1 GO 后才做。

### 13.1 robust perception control

先训练 corruption/noise-aware anatomy model，再测 q1/q2/q3。

如果 robust A 让 host failures 压回 reference-instability floor，则停止 claim “relation model is required for degradation rescue”。

### 13.2 Error propagation

对同一 lesion 测：
- ΔA = anatomy error change
- ΔU = lesion perception error change
- ΔR = relation error change

重点分析 small ΔA / ΔU 是否导致 large ΔR，但不把 ratio 类指标作为唯一主结论。

## 19. 当前执行顺序（v2.6 十步）

6. 100–150 病灶双阅片 pilot（两层系列都覆盖），得实测一致率、ICC、p_disc、读片时间（§7.2）。
7. 用 pilot 做患者聚簇模拟，比较方案 A / B 的功效与工时，冻结 final N 与主人群（§8.4、§9）；同时按 §10.1 的升级规则决定训练标签阶段。

9. Level R 主实验：按折读片，700 例中期无效性分析（§12.8），最终 Gate R1 统计（§12）。
10. 只有 Gate R1 = GO，再做鲁棒性（§13）、脑侧检测器、E（§14）、欠采 / 运动 / 扫描仪 / 多器官扩展。

## 21. Go / No-Go 总表

Gate 0 GO：coordinate transforms verified，折按患者划分。否则停止后续 U/R。

Gate 0.5 GO：在冻结的 t 下困难组占比 ≥ 15%。否则关系主线降级为退路，不投入读片。

Gate R0 GO：全体 raw 一致率 CI 下限 ≥ 0.80 且 H1 raw ≥ 0.70。否则把 single-host endpoint 改为 set-valued/topographic endpoint（分层执行）。

Gate R1 GO：
- 95% CI(net rescue vs Bgeo+) > 0
- B4 > Bprior
- B4 > Bgeo+
- B4 > B2

Robustness Gate GO：robust perception 不能解释掉 relation failures。否则停止 relation-rescue claim。

E Gate：仅当 R1 GO 且仍有 residual relation failures。

## 22. 第一篇论文最稳叙事

核心：

Anatomy-centered structured MRI perception with independently validated lesion–anatomy binding.

主科学问题：

Does learned lesion–anatomy binding provide information beyond strong geometry and local appearance when evaluated against independent human relation truth?

第二层问题：

How do anatomy and lesion perception errors propagate into relation errors under controlled MRI perturbation?

不要把 novelty 放在：
- joint segmentation
- Transformer
- foundation model
- pseudo-label consistency

真正的 novelty 必须由：
- independent R truth
- dangerous geometry baselines
- fair geometry parity
- population-level net rescue

共同支撑。

## 25. 决定记录（2026-09-22）

依据：PR #6 评审留下的 5 项未决、`REVIEW_v2.5_feasibility_2026-09-22.md`、外部 review 及其核验（`REVIEW_external_experiment_design_2026-09-22.md`，脚本与输出在 `docs/verification/2026-09-22-external-review-check/`），以及用户 2026-09-22 的拍板（"吸收外部 review"、B4 两种证据都用、"先用软件算"、B2 按建议绑定）。Gate 0.5 之前可推翻，之后冻结。

1. **一致率门槛**：两层 raw 门，全体 CI 下限 ≥ 0.80、H1 点估计 ≥ 0.70；κ / AC1 只报告。不采纳"AC1 ≥ 0.6"（按探针分布仅相当于 raw 0.65）。
2. **样本设计**：排除单一 20% 留出。方案 A（全标 1297）与方案 B（H1 全标 + H2 概率抽样）在 pilot 后用患者聚簇模拟择一，工时按分层实测读片时间算；不预设方案 B 省时（解析与模拟都表明每小时信息量相近）。
3. **主终点**：全部病灶，集合值正确性；singleton rate 报告；确定病灶子集单列。
4. **脑室 / CSF**：只作地标，脑室内病灶记 other。
5. **H1**：病灶表面到任意两块候选脑区交界面的距离 ≤ t，t 在 Gate 0.5 后、模型前冻结（初值 3 mm，{2, 3, 4, 5} 中取占比 ≥ 15% 的最小值）；同时记录 Δd。
6. **B4 的局部证据**同时用图像小块与候选距离图；结构细节从 §10.1 的初值出发，在预注册范围内按内层 CV 调整。
7. **训练标签**先用伪标签；医生标签微调为预注册升级路径，触发条件见 §10.1。
8. **B2** 的小块与 B4 的病灶编码器绑定。

仍待定（不阻塞 Gate 0 / 0.5）：读片人姓名、裁定人、临床负责人、标注工具、伦理备案；t 的数值（Gate 0.5 后）；final N 与主人群（pilot 后）；训练标签是否升级（pilot 后）。
