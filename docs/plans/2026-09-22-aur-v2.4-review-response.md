日期：2026-09-22  
状态：**v2.4 执行计划（supersedes v2.3 的 clean-R first gate）**  
基线：PR #4 @ `437778a`  
触发：PR #4 review `pullrequestreview-5274086790`

## 0. 一页结论

### 0.1 第一原则不变

项目最终目标仍然是：

```
MRI
  ↓
A: Anatomy parsing
  ↓
U: Lesion type + 3D localization
  ↓
R: Explicit lesion-to-anatomy binding
```

形式化为：

```
X → (A, U) → R
```

其中：

- **A**：解剖实体身份、mask/空间支撑、物理位置、anatomy token；
- **U**：病灶类型、3D box/mask、毫米坐标、大小、lesion token；
- **R**：每个病灶属于哪个解剖结构，第一阶段以 primary host 为主。

### 0.2 v2.3 的关键修正

v2.3 把第一道门写成：

> clean / standard condition 下，固定同一 A/U 上游，Brel 必须赢过 Bprior、Bgeo+、Broi。

这一定义在现有数据上不能直接执行：

1. **SKM-TEA 膝**：class-aware seg-then-lookup 已达约 0.958–0.968，理论余量只剩约 3–4 个百分点；当前 311 lesion 在 patient clustering 后有效样本约 215–240，无法把 3 个点左右的差稳定作为第一道门。
2. **fastMRI+ 脑**：现有 clean host reference 来自 SynthSeg + geometry lookup；若把它当 truth，则 B0 与 reference 同源，clean B0 按定义占据近似“自洽上限”，无法用它证明 learned R 更正确。
3. 因此，**独立 Level R 人工关系真值必须先于 R superiority test**。

新的第一道科学门不再是 clean pseudo-reference 上的 Brel > Bgeo+，而是：

> **先建立独立 Level R，再判断 learned relation 是否在相同 A/U、相同 geometry 条件下提供超出 prior / geometry / local ROI 的净收益。**

## 1. 当前证据账本

### 1.1 已确认成立

1. A/U/R 是合理的最终任务分解：anatomy、lesion、binding 是三个不同层次。
2. SKM-TEA 的 clean located-in 任务大部分可由 class-aware geometry lookup 解决。
3. SKM-TEA 在现有 noise / undersampling 下几乎不产生有效 geometry-conflict subset，因此不适合作为 relation robustness 主战场。
4. fastMRI+ FLAIR 小病灶在 noise q1→q3 下存在递增 host-change window，q3 约 7.4%，且 global anatomy 尚未整体崩溃。
5. clean SynthSeg host assignment 对 benign processing 自身存在约 3–6% instability，因此 pseudo-reference 不能承担最终 clinical correctness。
6. training-free preprocessing 没有消除 q3 host-change window。
7. PR #4 的新增代码工程上可运行；专家已在临时导出目录跑完整测试，311 passed。

### 1.2 尚未成立

1. 尚未证明 learned R 比 strong geometry 更正确。
2. 尚未建立脑侧独立的人标 Level R。
3. 尚未实现公平的 Bprior / Bgeo+ / Broi。
4. PR #4 中的 `HostCompetitionHead` 实质是 **B1 independent candidate MLP**，不是 B3。
5. 当前 relation geometry 仍只有 5D `Δx/Δy/Δz/||d||/IoA`，不足以与强 Bgeo+ 做公平比较。
6. fastMRI+ box vertical flip 尚未进入正式 data engine。
7. 既往 H1 detector failure 被 box-direction bug 污染，不能继续作为最终 detector verdict。

## 2. 新的论文级问题定义

第一篇不再问：

> “我们设计了一个 Relation Transformer，它是否优于 lookup？”

改为两个层级问题。

### Q1：核心 structured perception

> Can a 3D MRI model explicitly represent anatomical entities and lesion entities, and assign each focal lesion to its anatomical host using an independently defined relation reference?

即：

```
X → A
X → U
(A, U) → R
```

### Q2：机制与鲁棒性

> When MRI evidence is perturbed, how do errors propagate through anatomy perception, lesion perception, and lesion–anatomy binding?

即：

```
X      → (A, U, R)
T_q(X) → (A^q, U^q, R^q)

measure ΔA, ΔU, ΔR
```

只有在 Q1 证明 R 有独立价值后，再继续 claim：

```
small perception error
→ amplified relation error
→ relation-aware rescue / abstention
```

---

## 3. 第一篇主动收缩的范围

### 3.1 主战场：brain focal lesions

第一篇 relation 主问题优先放在：

```
small focal brain lesion anatomical binding
```

原因：

- 候选解剖结构密集；
- 小病灶靠近 cortex / white matter / ventricle 等边界时 geometry ambiguity 更真实；
- 已观察到 q1–q3 递增的 host-change regime；
- 膝关节 class-aware geometry 已接近 ceiling，不适合作为 learned R superiority 主战场。

### 3.2 SKM-TEA 的新角色

SKM-TEA 保留，但角色改为：

1. **显式 tissue_id relation truth 的 sanity check**；
2. **geometry-easy negative control**；
3. 验证一个合理的 relation model 在简单场景下不能比 lookup 制造更多 harm；
4. 不再承担“clean relation 必须显著赢 lookup”的主要统计结论。

### 3.3 多器官目标仍保留，但不在第一篇强 claim

长期目标仍是：

```
brain + knee + spine + abdomen + ...
```

统一 A/U/R interface。

第一篇只证明：

- 核心 interface 可工作；
- brain relation problem 非平凡；
- knee 作为 geometry-dominant 对照；
- 不宣称已实现通用 MRI foundation model。

## 7. Stage R0：先建立独立 Level R

### 7.1 为什么必须前置

当前脑侧 pseudo relation：

```
R_pseudo = lookup(SynthSeg anatomy, lesion box/mask)
```

因此：

```
B0 ≈ definition of R_pseudo
```

在此 reference 上比较：

```
Brel vs B0
```

不能回答谁更 clinically correct。

所以：

```
Level R → before Gate R
```

而不是 v2.3 的“先跑 R，再补人标”。

### 7.2 Level R 的标注单位

每个 lesion independently 标：

```
primary_host
secondary_involved_structures (optional)
adjacent_structure (optional)
confidence
ambiguous_flag
```

第一篇 primary endpoint 只使用：

```
primary_host
```

但保留：

```
multi-structure / ambiguous
```

出口，不强迫所有大病灶成为单一 host。

### 7.3 Pilot 设计

不直接拍脑袋固定“最终 400 lesion”。

先做一个 **power-estimation pilot**：

- 优先抽 geometry-conflict / near-boundary lesion；
- 加 2–3 倍 matched stable controls；
- patient-level sampling；
- 两名 reader 独立标注；
- disagreement 由第三人或 consensus adjudication；
- 所有 pilot lesion 双阅片。

pilot 至少需要估计：

```
p_discord = P(method A != method B)
reader agreement
ambiguous rate
host-class distribution
per-patient lesion clustering
```

完成 pilot 后再锁定最终 N。

### 7.4 最终样本量

使用 paired correctness difference：

```
d = accuracy(Brel) - accuracy(Bgeo+)
```

与实测：

```
p_disc = P(Brel != Bgeo+)
```

重新计算 McNemar / clustered design power。

不再复用 SKM-TEA §9.7 的固定 470 / 700 数字作为 brain relation 的最终样本量。

最终统计以 patient-level cluster bootstrap 为主，McNemar 作为补充。

## 8. Stage R1：固定所有 baseline，再实现 relation

所有方法共享：

- 同一 lesion instances；
- 同一 anatomy outputs；
- 同一 candidate ontology；
- 同一 patient split；
- 同一基础 geometry features；
- 同一 Level R truth。

### B0 — deterministic geometry lookup

```
class-aware overlap
→ zero-overlap nearest candidate
```

### Bprior — host prior

```
P(host | lesion type, side, coarse location)
```

包括：

- majority host；
- type-conditioned prior；
- type + side + coarse-location prior。

### Bgeo+ — strong geometry model

输入统一扩展 geometry。

模型至少包括：

- logistic regression；
- XGBoost 或等价 tree baseline；
- 2-layer MLP。

### B1 — independent candidate MLP

当前 PR #4 的 `HostCompetitionHead` 实质属于这一类。

正式命名：

```
B1 = independent candidate scorer + host softmax
```

不把 softmax normalization 本身解释为 candidate reasoning。

### B2 — direct local ROI classifier

```
local lesion ROI/context → host
```

不显式构造 anatomy–lesion pair。

### B3 — candidate-interaction host competition

对固定 lesion j：

```
z_ij = Fuse(a_i, u_j, g_ij)
Z_j  = {z_1j, ..., z_Kj}

Z_j
  ↓ 1–2 layers self-attention over K candidates only
Z'_j
  ↓
softmax over host candidates + none
```

禁止默认跨 lesion attention。

因此：

```
lesion j cannot alter lesion j'
```

除非未来有独立实验支持 cross-lesion reasoning。

### B4 — B3 + local boundary/image evidence

```
z_ij = Fuse(
    anatomy embedding,
    lesion embedding,
    shared geometry,
    local boundary evidence
)
```

B4 才是第一篇 relation 主模型候选。

### B5 — oracle / upper bound

使用 clean / GT geometry。

只作 ceiling，不参与 superiority claim。

## 9. Geometry parity：Bgeo+ 与 Brel 必须吃同一套几何

### 9.1 当前 5D geometry 不够

当前：

```
Δx, Δy, Δz, ||d||, IoA
```

只能作为 B1 prototype。

### 9.2 统一基础 geometry

推荐基础向量：

```
g_ij = [
    Δx_mm,
    Δy_mm,
    Δz_mm,
    centroid_distance_mm,
    signed_distance_to_candidate_surface,
    minimum_surface_distance,
    IoA,
    soft_overlap,
    lesion_extent_x_mm,
    lesion_extent_y_mm,
    lesion_extent_z_mm,
    lesion_volume_mm3,
    spacing_x,
    spacing_y,
    spacing_z,
    slice_thickness
]
```

### 9.3 Organ-specific landmark features

brain 可额外定义：

```
distance_to_cortex
distance_to_ventricle
hemisphere
```

但必须满足：

> 只要 Brel 使用，Bgeo+ 也必须获得同一 feature。

relation 唯一允许额外拥有的是：

- learned anatomy representation；
- learned lesion representation；
- local image / boundary evidence。

这样才能把增益解释为 beyond geometry。

## 10. Gate R：relation 是否有独立价值

### 10.1 Gate R 只在人标 Level R 上定义

pseudo-reference：

```
C1: clean lookup reference
C2: benign-processing stability
```

只用于训练 / debugging / stratification。

最终 correctness：

```
R: radiologist relation reference
```

### 10.2 Primary metrics

全 lesion：

- host accuracy；
- macro-F1；
- balanced accuracy；
- top-k host accuracy；
- net rescue；
- patient-level bootstrap 95% CI。

定义：

```
rescue = B0/Bgeo+ wrong and B4 correct
harm   = B0/Bgeo+ correct and B4 wrong
net rescue = rescue - harm
```

### 10.3 Gate R Go

至少满足：

```
95% CI(net rescue vs Bgeo+) > 0
B4 > Bprior
B4 > Bgeo+
B4 > B2
```

并且：

- 改善不是只来自 lesion type / coarse location prior；
- ambiguous cases 不被偷偷强制转成确定标签；
- patient-level aggregation 后仍成立。

### 10.4 Gate R No-Go

以下任一成立：

1. Bgeo+ 与 B4 打平；
2. B2 与 B4 打平；
3. pseudo-reference 上提升、人标 Level R 上没有净收益；
4. B4 的增益可完全由 anatomy prior 解释。

No-Go 含义：

> 停止把 learned relation 作为主要方法贡献。

但 A/U structured perception 项目继续。

## 11. Gate A′：只约束 robustness claim，不再决定整个项目生死

在 Gate R 之后，才研究 degradation-specific mechanism。

训练：

```
noise / corruption-aware robust anatomy segmenter
```

重新测试：

```
q1 / q2 / q3
```

若 robust A 已把 host-change 压回 reference-instability floor：

> 停止 claim “relation rescue is required under degradation”。

但这不否定：

```
X → (A,U) → R
```

的 clean/standard structured perception 任务。

## 12. Robustness：改成 error propagation study

对同一 lesion：

```
clean:     (A, U, R)
degraded:  (A^q, U^q, R^q)
```

分别测：

```
ΔA
ΔU
ΔR
```

核心机制指标：

```
relation amplification
= ΔR / (ε + normalized ΔA + normalized ΔU)
```

该指标只作为 exploratory analysis，主论文仍报告可解释的原始指标：

- anatomy boundary displacement；
- lesion center displacement；
- lesion classification change；
- host change；
- net rescue；
- harm。

若出现：

```
small ΔA / ΔU
→ large ΔR
```

才支持“relation-level amplification”。

## 13. Reliability E 的位置

E 不再与 A/U/R 并列作为第一阶段核心模块。

只有：

```
Gate R = Go
```

后才进入：

```
E_j = P(R_j correct | X)
```

baseline：

- max softmax；
- entropy；
- anatomy uncertainty；
- lesion detection uncertainty；
- local NRMSE；
- ConfidNet-like failure predictor。

评估必须：

```
within the same degradation severity
```

防止 E 只学到 q1/q2/q3 的 severity shortcut。

## 19. 论文主张边界

### 可以主张

如果 Gate R 通过：

> Explicit lesion–anatomy modeling adds information beyond priors, strong geometry, and direct local appearance for focal brain lesion host assignment.

如果 robustness 也成立：

> Acquisition perturbations can amplify local perception errors into lesion–anatomy binding errors, and relation-aware evidence can recover a subset of these failures.

### 不可以提前主张

- “MRI foundation model”；
- “general lesion understanding”；
- “Relation Transformer is necessary”；
- “pseudo-reference recovery equals clinical correction”；
- “joint anatomy-lesion segmentation itself is novel”。

## 20. 当前代码的正式解释

### `RelationModule`

旧 global K×M pair Transformer：

```
status = legacy / ablation
```

### PR #4 `HostCompetitionHead`

按当前实现应解释为：

```
status = B1 independent candidate MLP prototype
```

原因：

- candidate 之间无 attention；
- lesion 之间无 interaction；
- 只有最终 softmax normalization。

后续应重命名为：

```
IndependentCandidateHead
```

真正 B3 另建：

```
CandidateCompetitionHead
```

并只在同一 lesion 的 K 个 host candidates 上做 1–2 层 interaction。
