# 膝侧数据引擎(SKM-TEA → M1)

M1 判据实验的数据来源。SKM-TEA 是全库唯一"病灶框 + 解剖分割 + 原始 k 空间"三者同时具备的数据集,所以退化视图不是仿真贴图,而是在真实多线圈 k 空间上做欠采与加噪后重建出来的。本文件记录约定、坑和实测数,代码见 `anatobind/data_engine/skmtea*.py`、`anatobind/data_engine/{resample,splits}.py` 与 `scripts/{build_skmtea_m1,verify_skmtea_frames}.py`。

## 输入

`/data2/congcong/data/FM_data` 下三个根,155 个扫描一一对应:

- `SKM-TEA/files_recon_calib-24/MTR_xxx.h5` — `kspace` (512, 512, 160, 2, C) complex64、`maps` (512, 512, 160, C, 1)、`target` (512, 512, 160, 2, 1)、`masks/poisson_{4,6,8,10,12,16}.0x` (416, 80) bool。8 个扫描 16 线圈,147 个 8 线圈;四个扫描的深度是 168/152/156/144 而非 160。
- `SKM-TEA_ltr/segmentation_masks/dicom-track/MTR_xxx.nii.gz` — 六类分割(髌/股/胫内/胫外软骨、内/外侧半月板)。
- `SKM-TEA_ltr/annotations/v1.0.0/{train,val,test}.json` — 476 条病灶记录,官方 86/33/36 划分,受试者与扫描在三划分间不重叠;数值 image/annotation id 是划分内局部编号,合并时必须加命名空间。

## 三条硬约定

### 1. k 空间是混合域,重建约定已实测

`kspace` 的轴 0(读出轴)**已经在图像域**,只有 ky、kz 还在 k 空间。所以重建是:

```
x = fftshift( ifftn( ifftshift(k, axes=(1,2)), axes=(1,2), norm="ortho" ), axes=(1,2) )
img = sum_c conj(maps_c) * x_c
```

MTR_001 回波 1 上与自带 `target` 的相关系数 **0.9963**。零填充泊松欠采 4×/8×/16× 分别为 **0.946 / 0.922 / 0.904**,退化梯度单调,没有饱和。

泊松掩膜存在采集网格 (416, 80) 上,比重建网格 (512, depth−80…) 小,须**居中嵌入**再乘;偏移用整除 `(ky - 416) // 2`。

噪声有两条约定,都是 2026-09-07 预检审计后定的:

- **只加在采集支撑上**。支撑是一个 (ky, kz) 图案,实测跨读出面与跨线圈完全一致(并集 = 交集 = 0.3854),取 `(k != 0).any(axis=(0, -1))` 即精确。原先加在整个网格上,61% 的噪声能量落在从未采样的线上,实际幅度是支撑限制版的 1.61 倍,且纹理是全 FOV 白噪声而非带限——那不是"更吵的扫描"的样子。改后 q1 实测 NRMSE 由 0.104 降到 0.064。
- **按线圈数归一到 8 线圈基准**。`noise_sigma` 取非零样本的 RMS,这是每线圈量、随 1/√C 变化;而线圈合成后的图像域噪声恰等于 sigma(因为 sum_c |S_c|² ≡ 1),所以不归一的话 16 线圈那 8 卷的噪声梯度比其余 147 卷弱 1.39 倍(实测两簇完全不重叠)。乘 `sqrt(C/8)` 后,16 线圈组 0.0667–0.0697、8 线圈组 0.0638–0.0663,整体极差比 1.091。8 线圈卷的值不变。

复高斯实部虚部各分 `sigma/sqrt(2)`。每卷各退化条件的实测 NRMSE 记进 `manifest.csv`——线圈混淆当初能隐形,就是因为没有任何地方记录梯度实际交付了多少。

### 2. 分割与 h5 不在同一坐标系,且有 18 个扫描要额外翻转

dicom-track 的 NIfTI 数组相对 h5 的 (x, y, z) 网格存成 (y, x, z),需 `transpose(1, 0, 2)`。**注解 JSON 的 orientation 第三轴写作 "RL" 的 18 个扫描(其余 137 个是 "LR")还要沿轴 2 镜像**。这条不是从 header 推出来的——NIfTI 的仿射轴码统一是 P/I/R,形状一致也不代表物理对齐——是靠对比度逐卷实测定下来的。

判据脚本 `scripts/verify_skmtea_frames.py`:回波 1 上,取髌软骨(1)与股软骨(2)各自"标签内均值 / 全部标签外均值"的**较小者**,要求 > 1.5 且大于同一指标在未变换数组上的值。结果 `docs/verification/skmtea_frames.csv`:**154/155 通过**,唯一不过的是 MTR_150(frame 1.408、identity 0.367),它输在 1.5 这条绝对线上,而不是输给未变换数组(1.408 仍是 0.367 的 3.8 倍)。

最初一版判据用"全部标签合并"算对比度,粗到 5 个扫描误判;拆到单条软骨标签取最小值后才把 RL 子集暴露出来。

### 3. 纳入规则 D5

`[x, y, z, w, h, d]` 里的 w/h/d 可以为负,所以端点必须排序后再判越界。三条筛除:非正范围、越界、类别与组织不相容(`Ligament Tear → Meniscus`、`Cartilage Lesion → ACL` 各一条)。

实测 **476 → 465**,分层为 **311 在分割内 / 116 关节积液 / 38 韧带**;剔除的 11 条 = 9 条非正范围 + 2 条类别不符,与方案 §5.1 完全一致。原始注解不改不删,筛选结果单独落 `annotations_screened.csv`,`keep` 与 `reason` 逐条可查。

## 宿主判定

半月板与胫骨软骨的 tissue_id 不带内外侧身份,所以不能直接一一映射到六个解剖 query。做法:把病灶框外扩 4 体素,数落在候选标签上的体素;内侧占比 ≥ 0.6 判内侧、≤ 0.4 判外侧、中间记 `ambiguous`,不强行指派。韧带(ACL/PCL)与积液在分割里没有对应标签,`host_label` 留空、`host_side` 记 `none`。

**单标签组织的宿主由 tissue_id 直接决定,重叠不得否决它**(方案 §5.1:tissue_id 是主真值,不由重叠反推)。髌软骨(tissue_id 5 → 标签 1)与股软骨(4 → 2)只有一个候选标签;若病灶框恰好不与掩膜重叠,记 `single_no_overlap` 并保留标签,而不是丢成无宿主。实测有 5 个主队列实例属于这种情况。两标签组织零重叠记 `unresolved`,与积液/韧带的 `none` 区分开,避免读表的人把软骨病灶误并入"无宿主"弃权类。`n_no_overlap` 与 `n_unresolved` 计入 `manifest.csv`。

## 重采样与划分

面内精确 2 倍块归约(层向不动):图像取块均值,框按 floor/ceil 缩放保证不丢体素。

**间距逐卷从分割 NIfTI 头读**,不能硬编码:MTR_049/066/095/173 是 180 mm FOV 重建,面内 0.35156 mm 而非 0.3125 mm,导出后是 0.7031 mm 而非 0.625 mm,差 12.5%。NIfTI 是 (y, x, z),所以 zooms 要和数组同样做 (1,0,2) 置换。间距逐卷写进 `manifest.csv`。

**标签的 2×2 块平局判给标签,不判给背景**。半对半的块本来就没有无偏解:判给背景在真实分割上系统性侵蚀 6%–12.7%,判给标签系统性膨胀 4%–18.5%。选后者不是因为它更准,而是因为偏的方向保守——掩膜变薄会降低框-掩膜重叠,专门损害"先分割再查表"的对照臂,等于给 M1 赌局偏向我方假设。

五折按扫描(= 受试者)分层:按扫描内"在分割内"的病灶数分 0 / 1–2 / ≥3 三层,层内定种子洗牌后轮流发牌,**计数器跨层连续**以免每层都从 0 折开始造成偏斜。实测 31 / 31 / 31 / 31 / 31。

## 导出

```
PYTHONNOUSERSITE=1 PYTHONPATH=. ~/anaconda3/envs/nvgen/bin/python scripts/build_skmtea_m1.py --workers 4
```

每个扫描一个目录,9 个文件:`image_clean_e{1,2}`(两个回波的干净幅值)、`image_noise_q{1,2,3}_e1`(k 空间加噪 0.25/0.5/1.0)、`image_us{4,8,16}_e1`(泊松欠采)、`seg.nii.gz`、`boxes.csv`。断点续跑看 `<scan>/boxes.csv` 是否存在;`manifest.csv` 每完成一卷就整体重写,记 status 与耗时。worker 内 `os.nice(19)`,这是共享机器。

实测:每卷 250–480 s、**285 MB**。155 卷 4 worker 外推约 4 h、44 GB。落盘前核过 `/data2` 剩 22 TB;峰值常驻内存实测外推每 worker 16 线圈卷 35 GiB、8 线圈卷 18 GiB,4 worker 最坏 141 GiB,对 898 GiB 可用。

09-07 预检审计前的两卷试跑(MTR_001/MTR_005)已因上述噪声、平局、间距三处改动作废,移到 `m1_pre_audit_fixes/` 保留。

**MTR_150 是文档化例外**:坐标系判据 154/155 过,它以 1.408 差在 1.5 这条绝对线上。诊断结论是变换正确、扫描异常——它属于 16 线圈组(该组对比度中位数 2.202 vs 8 线圈 3.789,p=8.8e-6),且髌软骨有三处 3 级全层缺损,标签 88.2% 的体素落在放射科医生独立画的病灶框内,标签内变异系数 1.14(对照 0.17–0.38),即该标签横跨残余软骨、积液与软骨下骨。所用变换在全部六个标签上都胜过 8 种翻转组合(1.408 vs 次优 1.288)。照常导出,不加白名单也不剔除。判据那条绝对阈值受线圈组与病情严重度混淆,留到跑完后连同混淆一起改。
