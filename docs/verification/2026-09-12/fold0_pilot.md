## 4. 对 G1/G2 的后果

G2 用的是 nnU-Net 的分割（正常）加上**我们检测头给的框和类别**。检测头在留出扫描上给不出框，G2 要比较的那批病灶（两张图都检出、类别都对）就是空集，门无法判定。多训四折不会改变这一点：问题在 124 卷、约 380 个病灶这个规模上的过拟合，不在步数。

## 6. 补充(同日晚):延长到 11250 步后重测,并更正第 3 节的归因

按收敛规则把 fold 0 延长到 11250 步(4.9 h)后重新缓存预测、重测:

```
                     7500 步              11250 步
mask 损失(末 50)    0.545               0.510
clean Dice 训练      0.453               0.492
clean Dice 留出      0.386               0.384
留出检出(七个视图)   0/84 全漏检          0/84 全漏检(us4 偶然命中 1 个)
```

**第 3 节把 mask 头的问题归为"欠拟合"是错的。** 继续训练只让训练扫描的 Dice 从 0.453 涨到 0.492,留出扫描原地不动(0.386 → 0.384),训练与留出的差距从 0.067 拉大到 0.108。这是泛化问题,不是没训够。

真正的原因是**样本量与增广**,两个头是同一个病:

- 本模型:124 个整卷 × 7 个视图,几何增广只有一次深度翻转(`anatobind/train/dataset_v2.py:94`,p=0.5)。等于反复看同样 124 个膝关节。
- nnU-Net:同一批扫描切成 1488 个训练例,每步随机取 patch,再叠加旋转、缩放、高斯噪声、高斯模糊、亮度、对比度、低分辨率模拟、gamma、镜像。留出伪 Dice 0.81–0.88。

也就是说,此前两个对照实验(热图项降权、像素解码器)都没打中要害:它们改的是网络和损失,而瓶颈在数据管线。**第一批不改**——mask 头不在判门路径上,G2 用 nnU-Net 的分割。真要让本模型的分割追上 nnU-Net,第二批需要 patch 采样 + 完整增广,那是数据管线的改动,不是模型的改动。

**对第一批报告的影响**:"B0 用本模型分割"这一列会明显弱于 nnU-Net 那一列,如实报告即可;判门路径不受影响。
