## 3. mask 头：训练和留出一样差，是欠拟合

clean 视图，逐结构 Dice 与预测/真值体积比：


训练扫描也只有 0.34–0.63，说明不是泛化问题，是没训到位：mask 项从 0.79 只降到 0.55，而同期 nnU-Net fold 0（250 epoch，训到 174 epoch）的伪 Dice 已是 0.81–0.88。原因大概率是热图项早期大两个量级（22 对 0.79），梯度裁剪到 1.0 后 mask 头实际学习率极小，加上 mask 头本身很浅。

## 4. 对 G1/G2 的后果

G2 用的是 nnU-Net 的分割（正常）加上**我们检测头给的框和类别**。检测头在留出扫描上给不出框，G2 要比较的那批病灶（两张图都检出、类别都对）就是空集，门无法判定。多训四折不会改变这一点：问题在 124 卷、约 380 个病灶这个规模上的过拟合，不在步数。
