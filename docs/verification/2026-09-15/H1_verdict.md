# 2026-09-15 H1 裁决：不通过。检测器学到了弱信号，但绝对标定塌陷

leg 2 spec §3.4 的 H1 是止损门：在投入建两个可靠性头之前，回答"检测器产出的东西够不够让可靠性头有东西可学"。

## 0. 裁决

**H1 不通过**，且不是因为阈值没调好——任何阈值都不行。

```
$PY scripts/check_h1.py
```

```
threshold 0.05 .. 0.95: scan-level positive rate on training folds 0.823 (每一档都是 0.823)
H1 FAIL: no threshold puts the scan-level positive rate in [0.2, 0.5]
```

扫描级正样本率在所有阈值上恒为 0.823，说明它不由阈值决定——由漏检决定，而漏检是任何阈值都调不出来的。

## 1. 训练本身正常

五折各训满 20000 步（批 16，25 个 epoch），损失从 140 收敛到 5.6：

| fold | 步数 | s/step | 末 50 步损失 |
|---|---|---|---|
| 0 | 20000 | 0.314 | 5.710 |
| 1 | 20000 | 0.184 | 5.539 |
| 2 | 20000 | 0.192 | 5.735 |
| 3 | 20000 | 0.196 | 5.647 |

（fold 0 前段实测 2.71 s/step，是与他人共用 GPU 时的排队；对方任务结束后降到 0.18。）

## 2. 检出的实际情况

留出卷的 clean 视图，抽样 300 卷：

```
真值病灶 1067 个（每卷 3.6 个）
3D 检出 208 个（每卷 0.7 个）
检出分数 min 0.050 / median 0.052 / max 0.067
  score >= 0.2 的检出：0 个
208 个检出中正确 2 个，正确率 0.010
163/300 的扫描纯因漏检而失败（没有任何错误检出）
```

最大分数 0.067 低于热图头的初始化值 0.1（`PRIOR_BIAS = -2.19`，sigmoid = 0.1）。模型主动把整张图压低了。

## 3. 但模型确实学到了东西

在 fold 0 的模型上探查真值中心处的热图值（56 个病灶）：

```
真值中心 5x5 邻域最大值：中位 0.0239
典型背景格：中位 0.0103
对比度 2.31 倍

真值中心在该类热图中的分位：87.9（随机为 50）
落在全图前 0.1% 的格子：0.0%
落在前 1%：7.1%
落在前 10%：42.9%
```

信号方向正确、强度不足。要能检出，真值中心必须排进最靠前的少数几个格子；而 160x160 的网格上"前 1%"仍有 256 个格子，只有 7.1% 的病灶能进去。

## 4. 为什么塌陷：损失的量级失衡

每个样本 160x160 网格 x 5 类 = 128000 个格子，正样本 1 到 3 个。CornerNet focal loss 按目标数归一化：

- 负样本项：128000 个格子，初始 p=0.1 时每个约 `p^2 * (-log(1-p))` = 0.001，合计约 134，除以 n_obj≈1.5 得约 85；
- 正样本项：1 到 3 个格子，每个 `(1-p)^2 * (-log p)` = 1.86，除以 n_obj 得约 2。

负样本项约为正样本项的 50 倍，梯度压倒性地指向"整体下压"。初始热图损失 133 与此吻合；降到 4.5 正是把 p 从 0.1 压到约 0.01 的结果。这是平凡解，不是学到了定位。

作为参照：CenterNet 用 stride 4（512 输入 -> 128x128 网格）并训练 140 个 epoch；本设置用 stride 2（320 输入 -> 160x160，格子数为其 1.56 倍）且只训了 25 个 epoch。

## 5. 结论与去向

H1 的设计目的正是拦住这种情况，它做到了：在把两个可靠性头、H2 与 H3 建到一个几乎什么都检不出的检测器上之前停了下来。这与 leg 1 训完五折才发现分析子集为空形成对照——那次的教训是有效的。

**已排除的解释**：训练没跑完（五折都满步且收敛）、数据管道错误（样本 12817/折，正负 55:45，增广经 Task 7 审查逐点验证）、匹配或标签逻辑错误（Task 9 六种情形逐一实测通过）。

**未排除的解释**，按可能性排序：损失量级失衡（第 4 节）、训练步数不足（25 vs 140 个 epoch）、模型容量偏小（3.46 M 参数）、网格过密（stride 2 vs 4）。
