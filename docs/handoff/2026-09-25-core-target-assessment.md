# 2026-09-25 核心目标现状判断（与用户讨论后记录）

核心目标三条：① 识别解剖组织；② 识别异常病灶；③ 识别病灶出现在哪块组织上。按现有证据逐条判断（数字出处在括号里）。

```
                 膝(SKM-TEA)                                      脑(fastMRI+ FLAIR 小病灶)
① 解剖组织        已实现: nnU-Net 六类留出 Dice 0.84–0.89              能用但没测过: SynthSeg 33 类伪标签,
                 (docs/verification/2026-09-23/knee_eval)            5 mm 层上没有真值(计划 2 也不给它设线)
② 异常病灶        没实现: 箱填 nnU-Net 大类正确灵敏度 0.254 @1.57 FP/卷  还没做; 79% 单层、42% 面内 ≤ 6 mm,预计更难;
                 (门 0.5); fastMRI+ 2.5D 重训后 0.091 @1.53 FP/卷      有 3D 掩膜的大病灶(肿瘤/转移/梗死,计划 2)反而好做
                 (docs/verification/2026-09-24/h1_rerun)
③ 病灶在哪块组织  给定病灶框时已实现: 组织族 0.96、内外侧 0.98          几何查表能给答案,但对错没人知道:
                 (标注者 tissue_id 为真值; 找到的病灶上 0.80/0.81)      42% 的病灶框里已跨两个脑区(gate05/brain_frame.md),
                                                                     只有医生读片(Level R)能判
```

判断：

- ① 与 ③ 能实现。③ 的前提是病灶先被找到：膝上病灶一旦给定，查表就 96% 以上，说明膝上难的是检测不是绑定；脑上难的反过来——5 mm 层厚下病灶贴着边界，"在哪块组织"本身就模糊，所以要医生读片才能知道几何查表错多少、学出来的关系模型能不能比它好。这就是 PR-B（Level R 读片协议与工具）存在的理由。
- ② 是卡脖子的一条。SKM-TEA 只有 465 个框，fastMRI+ 有 1.6 万但是 2D 厚层，两个检测器都吃不饱。下一步用 nnDetection 在膝上最后试一次；再不行，诚实的结论是"用现有数据做不到全自动检测"，系统退成半自动：病灶由放射科医生标出，系统给出它在哪块结构上、多大、跨不跨边界。这仍然可发；v2.6 把论文主实验定为"给定病灶 + 预测解剖 → 关系"（§6.3）正是为了不被 ② 拖死。

这个判断不改变已定的顺序：先做 PR-B（spec `docs/superpowers/specs/2026-09-25-level-r-annotation-tooling-design.md`），nnDetection 在 GPU 空时并行。
