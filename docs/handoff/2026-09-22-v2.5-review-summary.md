## 2. 先讲清几个词

这个项目做的事一句话：给一张脑部 MRI，先把脑分成一块块区域（A，解剖分区），再把病灶找出来（U，病灶检出），最后回答"每个病灶落在哪块区域里"（R，关系）。仓库里把"病灶所在的那块脑区"叫**宿主**（host），下文两种说法混用。

- **查表法（B0）**：先分区，看病灶框和哪块区域重叠最多，就说它在那块。不用学习。
- **强几何基线（Bgeo+）**：把病灶到各区域的距离、重叠面积等十几个数字喂给普通分类器。比查表强。
- **关系模型（B3/B4）**：看图像的神经网络。论文要证明它比 Bgeo+ 更准。
- **伪标签**：算法自动生成、没人核对过的标签。脑侧现在的分区来自 SynthSeg 软件，就是伪标签。
- **Level R / 独立真值**：放射科医生亲手标的"这个病灶在哪块区域"。唯一的标准答案。
- **留出集**：训练时藏起来不用、专门用来考试的患者。
- **盲化 / 解盲**：医生标注时看不到任何模型答案；标完再拿模型答案来对。
- **裁定**：两位医生意见不一致时，第三位医生或事先约好的规则来定。
- **Gate（门）**：每一步"过或不过"的关卡，不过就不做下一步。

## 3. 评审结论：有条件 GO

有条件 GO 的意思是：可以继续，但要满足 §6 列的五个条件。评审的一句话判断：**这个项目最大的风险不是做不出来，而是做出来结果是阴性。**

五点理由：

1. **余量薄。** 探针 24 卷里 78.7% 的小病灶（614/780）查表判出来就在白质里，几何基线和神经网络必然给同一个答案。两种方法能分出胜负的病灶只剩两成上下。评审估计两法的净差距只有 1 到 4 个百分点（推算，不是实测）。
2. **功效被高估。** 方案里的样本量公式沿用了膝盖数据的设计效应 1.3 到 1.5。但脑侧每个患者的小病灶数极度偏斜：中位 3 个、最多 87 个，前 10 个患者占了 38.3%。同一患者的多个病灶不独立，样本要打的折远比想的大（聚簇尺寸 m_eff = 29.45；患者内相关 0.02 时设计效应 1.57，0.05 时 2.42）。用全部 1297 个小病灶做五折交叉验证，勉强能检出 3 到 4 个点的差距；用单一 20% 留出，任何合理假设下都检不出。
3. **医生读片是最长的那根杆。** 全集双人读片按每例 1.5 / 2.5 / 4 分钟算，总工时 65 / 108 / 173 小时，另加裁定约 16 小时。人选、时间、裁定人、工具都还没定。
4. **病灶检出这一环没证明过。** 膝盖的检测器训在上下镜像的框上，修完框要重跑；脑侧的检测器连设计都没有。脑小病灶 79.3% 只占一层、42% 面内不超过 6 mm。第一篇很可能只能做"给定病灶框"的关系实验。
5. **工程缺口具体但可控。** 框翻转修复、B3、B4、Bprior、Bgeo+、B2、统计模块、标注工具全都还不存在，但每块都是几百行的小模块，PR-A 到 PR-D 合计约 8 到 12 周。

## 4. 五件要拍板的事，评审的独立建议

这五项写在 v2.5 计划 §25，评审的建议在其 §7。下表留了"决定"一栏，拍板后填。

| # | 事项 | 评审建议 | 选错的后果 | 决定 |
|---|---|---|---|---|
| 1 | 医生间一致率的门槛用什么量纲 | 用两位医生直接一致的比例（raw），全体的 95% 置信区间下限不低于 0.80；κ 与 Gwet AC1 只作报告；某分层 raw 低于 0.80 就降为集合值终点。**不采纳"AC1 不低于 0.6"**：按探针的宿主分布它只相当于 raw 约 0.65，比现行 0.80 还松。 | 门太松，标准答案本身是噪声，3 到 4 个点的差距被淹没；门太严（0.90），近皮层分层必然被降级，模型唯一可能赢的地方消失。 | |
| 2 | 五折交叉验证全集，还是单一留出 | 五折患者级交叉验证，标全部 1297 个小病灶；按折推进读片，读到约 700 例时做一次"没戏就停"的中期分析（只许停，不许宣称）。单一留出直接排除。 | 留出等于花几十小时读片换一个必然跨零的置信区间。 | |
| 3 | 主终点算哪些病灶 | 全部病灶；用"模型答案是否落在医生给的可接受集合里"判对错；确定病灶子集单独报告，并报告覆盖率。 | 只算"确定"病灶等于把困难病例剔掉，模型可能赢的地方正好被抹掉。 | |
| 4 | 脑室算不算病灶所在脑区 | 不算。脑室与脑脊液只作地标；真正的脑室内病灶记为 other，不进准确率。 | 探针干净图就有 19 个病灶被查表判给脑脊液，那是伪标签错误；若脑室算宿主，模型在这 2.4% 上白得分数。 | |
| 5 | 困难组（H1）怎么定义 | 纯几何：病灶中心到最近的其他候选脑区边界不超过 t mm，在干净 SynthSeg 上算，t 在任何模型存在前冻结；t = 3 mm 时困难组约占两成（待全集实算）。 | 用"方法不一致"定义会让抽样和结局相关，加权估计失效，而且模型没建出来前算不出。 | |

## 5. 评审顺手发现并已修正的文档错误

- STATUS 与 v2.5 §25 写"两位读者各读约 2600 例，每例 1.5 分钟约 32 小时"。实际 2600 是两人合计，每人约 1300 例才对应 32 小时。已改。
- STATUS 写"约 79% 小病灶完全在白质内"当全集事实。它来自按病灶数挑出的 24 卷，且是"查表宿主为白质"的比例，全集没测过。已改口径。
- 一致率门槛的两个备选（AC1 不低于 0.6、raw 不低于 0.90）被当作等价写在一起，实际差 25 个百分点。已加注记。
- 旧研究计划里 Bgeo+ 仍写"XGBoost 类"，v2.5 已改为不新增该依赖且环境未装。已统一。

未改、只登记的：leg 2 规格里 H1 门的定义与 `scripts/check_h1.py` 的实现不一致，裁决按代码写；重跑 H1 时一并修正。

## 6. 评审给的五个条件与停止规则

条件：

1. §25 第 2 项定为五折交叉验证全集，样本量表用 m_eff = 29.45 与试标实测的患者内相关重算。
2. Gate 0（修框）与膝侧 H1 重跑两周内完成并落盘；脑侧读框、合并、翻转、查表代码从探针脚本移入仓库并加测试。
3. 读片人、裁定人、工具在 PR-C 开工前定名；试标六周内完成，按分层报告 raw 一致率与困难组占比。
4. 预注册文档在任何人标与模型输出对接前冻结：Bgeo+ 特征清单、B4 结构与超参、主终点、分层定义、中期无效性规则。
5. 停止规则写死：试标里困难组 raw 一致率低于 0.75，或困难组占全体不到 15%，或 700 例中期分析净差距的置信区间上限低于 0.02，则停 PR-D，第一篇改为退路版本。

退路论文（Gate R1 阴性时）：发布 1297 个病灶的双阅片关系真值，报告几何绑定在人标上的准确率与失败模式，加膝侧对照与噪声下的误差传播。标注是资产，负结论也有信息量；但作为方法论文投 MedIA 把握不大，更合适的是数据类期刊加一篇基准分析。
