Level R 读片说明

这项工作要回答的是：每一个标出的脑内小病灶是什么、在哪一侧哪个脑叶、长在哪块解剖结构上。您看到的是 FLAIR 轴位图，绿框是待判的病灶（由公开数据集的标注者标出）。两位医生各自独立读，互不可见对方答案；第三位医生只裁分歧。工具里不显示任何自动分区或模型结果。

怎么看图

  • ↑↓ 或 ←→ 翻层，滑条也可以；病灶所在层在标题里标出"（病灶层）"。请上下多看几层再判。
  • 1× / 2× / 4× 放大，以病灶框为中心；默认 2×。
  • 在图上按住拖动：横向改窗宽、纵向改窗位；"复位窗"回默认。右侧小图是上一层、下一层。

各字段怎么填

病灶类型

  • 非特异性白质病灶：FLAIR 高信号，无梗死征象。
  • 腔隙性梗死：3–15 mm，中心 CSF 样低信号，周围高信号环。
  • 血管周围间隙：沿穿支血管走行，CSF 信号，无高信号环。
  • 其他：以上都不像时选，可在备注里写一句您的判断。

侧别

图像左侧 / 图像右侧 / 中线。以屏幕左右为准，不是患者左右：病灶在屏幕上脑中线的左边选"图像左侧"，右边选"图像右侧"，位于中线或跨越中线选"中线"。请直接按屏幕回答，不要换算成患者左右，全体数据由我们事后统一换算。放大后看不到中线时可切回 1×。

脑叶

额叶、顶叶、颞叶、枕叶、岛叶。病灶在深部灰质（丘脑、基底节）、脑干或小脑时选"不适用"。

主宿主结构（primary_host）

定义：结合整个可见 MRI 体积，您判断该病灶最主要、最合理的解剖宿主组织。它不是框内重叠最大的结构，也不是离框最近的结构，而是您作为放射科医生对"这个病灶长在哪"的判断。可选：白质、皮层、丘脑、基底节、脑干、小脑、其他（含脑室内病灶）。脑室与脑脊液不算宿主，脑室内病灶选"其他"，并在拓扑位置选"脑室旁"、邻接选"邻近脑室"。

可接受的宿主（acceptable_hosts）

最多 2 个，必须包含主宿主。5 mm 层厚下贴着边界的病灶常常分不清白质还是皮层：这时主宿主填最可能的一个，另一个合理的宿主加进可接受集合。例：主宿主 = 白质，拓扑 = 近皮层，可接受 = {白质, 皮层}。不要把"近皮层"当成宿主。

拓扑位置（topography）

脑室旁、近皮层、皮层内、深部白质、幕下。描述病灶在哪一带，和宿主是两个独立的问题。

邻接（adjacency）

可多选：邻近皮层、邻近脑室、跨越边界；都不是就选"无"（选了"无"不能再选其他）。

不确定性（ambiguity）

确定 / 两个宿主难分 / 多结构 / 分辨率不足。"两个宿主难分"时可接受集合通常应有 2 个。

不是病灶

框里没有您认可的病灶（标错、血管、伪影）时勾选；勾选后病灶类型、侧别、脑叶和宿主都不用填。这类框会单独统计，不进主终点。框里是血管周围间隙时不勾这一项，在病灶类型里选"血管周围间隙"。

局部图像质量、信心

质量指病灶附近能否看清结构边界（好 / 一般 / 差）；信心 1（低）到 5（高）指您对主宿主判断的把握。

备注

自由填写。任何让您犹豫的地方都值得写一句。
